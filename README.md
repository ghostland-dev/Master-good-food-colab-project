# Good Food Platform

Microservice-based food ordering platform (team project).

## Features

- React + Vite web app with Supabase
- Catalogue microservice
- API gateway configuration
- Docker, Terraform and GitHub Actions

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- React Router
- Supabase
- C# / .NET
- Docker
- Terraform
- GitHub Actions

## Getting Started

```bash
git clone https://github.com/ghostland-dev/good-food-microservices.git
cd good-food-microservices
cd app-web
cp .env.example .env   # then fill in your own values
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview

## Deploy

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fghostland-dev%2Fgood-food-microservices&root-directory=app-web)

Click the button to deploy your own copy on Vercel in one step.

The app lives in the `app-web` folder, which the button sets as the Vercel root directory.
